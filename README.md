# ASCII Webcam

A real-time webcam to ASCII art converter that displays the output in your terminal.

## Installation

1. Clone this repository:
```bash
git clone https://github.com/yourusername/ascii-webcam.git
cd ascii-webcam
```

2. Create and activate a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows, use: venv\Scripts\activate
```

3. Install the package:
```bash
pip install -e .
```

## Usage

Simply run:
```bash
ascii-webcam
```

Press 'q' to quit the application.

## Features

- Real-time webcam feed to ASCII art conversion
- Automatic terminal size detection
- Contrast enhancement
- Horizontal flip for natural "mirror" effect

## Requirements

- Python 3.6+
- OpenCV
- NumPy
